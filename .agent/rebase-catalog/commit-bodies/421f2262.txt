body:
Add cx/transcribe (codex/transcribe) to the STT registry and dashboard,
reusing existing Codex OAuth chat connections instead of an OpenAI API key.

Audio is converted to mono 24 kHz PCM16 WAV with ffmpeg and sent as a
file-only multipart request to ChatGPT's transcription endpoint using the
Codex identity headers. Responses are limited to {text} or plain text.

Input, decoded duration, conversion, response size and concurrency are
bounded, and private temp files are removed on both success and failure.
Token refresh, one forced 401 retry, connection proxy resolution and
account fallback reuse the existing persisted credential service. Direct
requests use Node HTTPS/1 with normal certificate verification while
proxied requests keep the shared transport.

Refs #5074
