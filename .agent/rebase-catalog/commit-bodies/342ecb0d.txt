subject: fix(pi-settings): declare existingProvider before use in POST
body:
The POST handler spread, defaulted and merged existingProvider but never
declared it, so every Pi "Apply Settings" request threw
`ReferenceError: existingProvider is not defined` and returned a generic 500.

Declare it from the existing provider block before the merge, which also
restores the intended merge of previously saved fields (e.g. api) instead of
silently dropping them.
