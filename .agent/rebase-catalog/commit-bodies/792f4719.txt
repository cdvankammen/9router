subject: fix(headroom): support native CommandCode requests
body:
CommandCode stores its conversation under params.messages, so Headroom
logged "unsupported commandcode request shape" and never called the
compression proxy.

Project the system prompt, text blocks, tool calls and text tool results
into OpenAI messages, then copy compressed text back into the original
fields. The CommandCode envelope, reasoning, images, tool ids/arguments,
schemas and non-text outputs stay untouched, and message count, roles and
tool-result ids are validated before any update is applied. Malformed
proxy responses and connection failures leave the request intact.

Refs #4552
